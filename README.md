# CURO MVP

CURO is a healthcare SaaS platform. This repository contains the initial feature-first scaffold for backend and frontend development.

## Structure

- `backend/` - API server and domain feature modules
- `frontend/` - React application with feature-first pages and shared UI
- `project-context.md` - Living project context and decision log

## Getting started

See `backend/README.md` and `frontend/README.md` after initial setup.
